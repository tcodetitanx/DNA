# DNA Analyzer

Comprehensive genome analysis and personality trait prediction system.

## Overview

This project analyzes raw 23andMe genome data to provide insights into personality-related genetic variants. The analysis focuses on scientifically-validated SNPs associated with neurotransmitter function, cognitive traits, and behavioral tendencies.

## Contents

- `genome_*.txt` - Raw 23andMe genome data files
- `analysis/` - Analysis scripts and databases
- `books/` - Generated PDF analysis books

## Subjects

1. **Ronin Fenix** (Daniel Taylor) - Volume 1+
2. **Katelyn Tingey** - Volume 1+

## Disclaimer

This analysis is for educational and research purposes only. Genetic associations with personality traits are complex, polygenic, and heavily influenced by environmental factors. The predictions and insights provided should not be used for medical decisions.
